## 👋 About me

I'm an IT undergraduate who loves building **enterprise software that solves real-world problems**. I like projects where several pieces have to work together: event pipelines, secured APIs, dashboards, containers and CI.

I also help run things off-screen: I'm active in INTECS (the IT society of my faculty) and was Project Co-Chairperson of *Weekly Tech Byte* at the Rotaract Club of University of Moratuwa.

## 🎯 Featured projects

### [SmartSupply Hub](https://github.com/Pasan-Yashobha/smartsupply-hub): supply chain integration platform

An enterprise-style platform built around an event-driven backbone.

- **Kafka event pipeline** with 10 partitions
- **Dual-database persistence** with upsert logic
- **JWT authentication** end to end (Spring Security, Bearer tokens)
- **React dashboard** with Recharts, Axios and Lucide icons
- **Fully containerised** with Docker Compose, with **CI via GitHub Actions**

`Java` `Spring Boot` `Spring Security` `Kafka` `React` `Recharts` `Docker` `GitHub Actions` `Linux (WSL2)`

### [Resumora](https://resumora-frontend.vercel.app): deployed full-stack app

Live on the web: frontend on Vercel, backend and MongoDB on Railway.

[Live demo](https://resumora-frontend.vercel.app) · [Frontend repo](https://github.com/Pasan-Yashobha/resumora-frontend) · [Backend repo](https://github.com/Pasan-Yashobha/resumora-backend)

### SerWise: online service marketplace (group project)

A marketplace for digital and physical services. **My part:** the analytics dashboard and the notification system.

### Whiteboard Art Plotter

An automated multi-tool drawing and erasing system for whiteboards.
