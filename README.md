## 👋 About Me

Hi, I'm **Pasan**, an IT undergraduate at the **University of Moratuwa** who loves building enterprise software that solves real-world problems. I work mostly with **Spring Boot, Kafka, and React**, and I enjoy projects where secured APIs, event pipelines, and Dockerized deployments all come together.

Beyond code, I'm active in **INTECS**, the IT society of my faculty, and served as **Project Co-Chairperson of Weekly Tech Byte** at the Rotaract Club of University of Moratuwa, an IT blog-writing initiative on modern tech trends.

## 🎯 Featured Projects

### [SmartSupply Hub](https://github.com/Pasan-Yashobha/smartsupply-hub): Supply Chain Integration Platform

An enterprise-style platform built around an event-driven backbone.

- **Kafka event pipeline** with 10 partitions
- **Dual-database persistence** with upsert logic
- **JWT authentication** end to end (Spring Security, Bearer tokens)
- **React dashboard** with Recharts, Axios and Lucide icons
- **Fully containerised** with Docker Compose and **CI via GitHub Actions**

`Java` `Spring Boot` `Spring Security` `Kafka` `React` `Recharts` `Docker` `GitHub Actions` `Linux (WSL2)`

### [Resumora](https://resumora-frontend.vercel.app): Deployed Full-Stack Application

Live on the web, with the frontend on Vercel and the backend plus MongoDB on Railway.

[Live Demo](https://resumora-frontend.vercel.app) · [Frontend Repo](https://github.com/Pasan-Yashobha/resumora-frontend) · [Backend Repo](https://github.com/Pasan-Yashobha/resumora-backend)

### SerWise: Online Service Marketplace *(group project)*

A marketplace for digital and physical services. **My contribution:** the analytics dashboard and the notification system.

### Whiteboard Art Plotter

An automated multi-tool drawing and erasing system for whiteboards.
